# 平台内容特征与爆款规律

## YouTube

分析重点：
- **标题-封面承诺 (Title-thumbnail promise)**：点击前向用户承诺了什么样的好奇心空缺或预期结果。
- **前 15-30 秒**：视频如何确认封面承诺并提前展示核心看点。
- **留存环 (Retention loops)**：开放式提问、章节过渡、冲突升级、画面或节奏打断（Pattern interrupts）。
- **权威与背书 (Authority and proof)**：数据、实例、资质背书、实验过程、前后对比证据。
- **长视频结构**：引入、背景交代、问题定义、章节展开、高潮/结论、复盘总结、行动呼吁 (CTA)。

常见可复用口播公式：
- “我尝试了 X 持续 Y 天，这是真正发生的变化。”
- “每个人都说 X，但他们忽略的底层细节是 Y。”
- “我分析了 N 个案例，并发现了一个可重复套用的规律。”

## 抖音 (Douyin)

分析重点：
- **前 1-3 秒**：视觉冲击、矛盾冲突、结果前置、直接利益呈现。
- **高密度节奏 (High-density rhythm)**：一个镜头表达一个观点，短句，快速字幕，高频场景转场。
- **评论区触发机制 (Comment triggers)**：争议性话题、身份标签挑衅、“你是不是也…”、选择性提问。
- **即时反馈 (Immediate payoff)**：避免长铺垫，在解释原因前先呈现结果或冲突。
- **竖屏原生特征**：大字号标题、醒目的主体、面部或动作特写。

常见可复用口播公式：
- “别再做 X 了，真正有效的方法是 Y。”
- “我用 X 解决了 Y，过程比你想的要简单得多。”
- “99% 的人都忽略了这个细节。”

## B站 (Bilibili)

分析重点：
- **UP主人设 (Blogger Persona)**：专业性、趣味性、真诚调侃、与粉丝的社区连接。
- **信息密度 (Knowledge density)**：分节清晰、案例详实、参考出处、横向对比、图表或实操录屏。
- **社区化语言**：梗、弹幕点、真诚的避坑提醒、“省流版”总结。
- **标题-封面一致性**：承诺需足够有趣，但避免过度营销或标题党。
- **完播驱动力**：章节式的悬念揭晓、渐进式呈现、实用的尾部总结。

常见可复用口播公式：
- “省流：X，但真正关键的细节是 Y。”
- “这期视频我们一次性把 X 讲透：从 A 到 B。”
- “看完这期你会明白：为什么 X 并不是你想的那样。”

## 跨平台改写与平移

当将某一平台的视频平移改写到另一平台时：
- **YouTube 改写为 抖音**：压缩背景铺垫，结果前置，拆分为多集系列，使每一集都包含一个高强度的爆点/段子。
- **抖音 改写为 YouTube**：增加背景语境、实验数据/证据支持、划分章节结构、丰富案例呈现、并添加视频留存环。
- **B站 改写为 抖音**：保留最核心的梗或观点，删除冗长的解释性铺垫，将硬核知识点转化为快速展示的视觉切片。
- **抖音 改写为 B站**：补充原理解释、详细案例、反面教材、注入UP主人设立场表达，并加上分章节的结论整理。
